# 🎵 Music Player

An interactive Music Player built using HTML, CSS, and JavaScript. This project provides a simple and user-friendly interface for playing music and controlling audio playback.

## ✨ Features

🎵 Music playback functionality  
▶️ Play and pause controls  
⏭️ Next and previous track navigation  
🎧 Audio playback using HTML5 audio  
🎨 Clean and attractive user interface  
📱 Responsive design  
⚡ Interactive controls using JavaScript  

## 🛠️ Technologies Used

- **HTML5** – Structure and audio elements
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Music playback controls and interactive functionality

## 🎯 Project Purpose

This project was created to practice fundamental frontend development concepts, including:

- HTML audio elements
- JavaScript event handling
- DOM manipulation
- Functions and conditional logic
- CSS styling and layout
- Interactive user interface development

## 🚀 How It Works

1. Open the Music Player application.
2. Select or play a music track.
3. Use the playback controls to play, pause, or navigate between tracks.
4. Enjoy music through the interactive player interface.
